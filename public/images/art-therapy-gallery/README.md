# גלריית דוגמאות עבודה מטיפול באמנות

תיקייה זו מכילה את התמונות המוצגות בגלריה בדף "מהו טיפול באמנות".

## הוספת תמונות

פשוט הוסף תמונות לתיקייה זו. הגלריה תטען אוטומטית את כל התמונות שנמצאות כאן.

### פורמטים נתמכים:
- JPG / JPEG
- PNG
- WebP
- GIF

### הערות:
- אין צורך לשנות שמות קבצים - הגלריה תטען את כל התמונות אוטומטית
- התמונות יוצגו לפי סדר אלפביתי
- מומלץ להשתמש בתמונות באיכות טובה (לפחות 400x400 פיקסלים)
